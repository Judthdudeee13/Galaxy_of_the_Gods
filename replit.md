# Galaxy of the Gods

A 2D game built with Python and Pygame.

## Tech Stack
- **Language:** Python 3.12
- **Game Framework:** pygame
- **Map Libraries:** pytmx, pyscroll
- **Package Manager:** pip (requirements.txt)

## Project Structure
- `main.py` — Entry point for the game
- `requirements.txt` — Python dependencies
- `game_logo.png` — Game logo asset

## Running the Project
The workflow "Start application" runs `python main.py` via VNC (desktop GUI display).

## Dependencies
Install with: `pip install -r requirements.txt`
- pygame
- pytmx
- pyscroll
